💳 Layer 3 – Transactions & Progress
Cart «session – no DB table»

Lưu trong Express req.session.cart, không có bảng DB.

  • int user_id
  • Course[] items
Purchased «entity»
  • int id (PK)
  • int user_id FK
  • int course_id FK
  • string course_title
  • timestamp purchased_at

Unique index: (user_id, course_id)

Enrollment «entity – legacy»
  • int id (PK)
  • int student_id FK
  • int course_id FK
  • timestamp enrolled_at

Còn dùng cho thống kê. Luồng mua dùng Purchased.

LectureProgress «entity»
  • int user_id FK
  • int lecture_id FK
  • int last_second
  • float watched_percent
  • bool is_completed
Watchlist «entity»
  • int user_id FK
  • int course_id FK
  • string course_title
  • timestamp added_at

Unique index: (user_id, course_id) – ON CONFLICT IGNORE

Feedback «entity»
  • int user_id FK
  • int course_id FK
  • int rating (1–5)
  • string comment
  • timestamp created_at

Upsert: mỗi user chỉ có 1 đánh giá/khoá học. DB trigger tự cập nhật courses.rating_avg.
